## ✨ Why JEE 2027 Master Tracker?

Most aspirants track their syllabus in physical notebooks and lose track of revision cycles, PYQ completion, and mock test analytics. **JEE 2027 Master Tracker** brings that exact register-style simplicity into a fast, dark-themed web app accessible anytime on mobile, tablet, or desktop.

> 🔗 **Try it live right now:** [https://raushansharmaweb.github.io/JEE-2027-Master-Tracker/](https://raushansharmaweb.github.io/JEE-2027-Master-Tracker/)

## 🚀 Key Features

| Module | What You Can Do |
| :--- | :--- |
| **📚 Pre-Loaded JEE Syllabus** | Complete **63 chapters** across Physics, Chemistry, and Mathematics with `★` **High Priority** tags based on recent NTA trends. |
| **✅ 3-Stage Chapter Checklists** | Track **Theory**, **Questions / DPP**, and **PYQs** individually for every single chapter with one-tap checkboxes. |
| **🔁 Revision Counter** | Keep count of exact revision rounds (`0x` → `1x` → `2x` → `3x+`) so high-weightage chapters never slip away. |
| **📝 Chapter Notes & PYQ Score** | Add quick formula reminders, weak topics, or chapter-wise PYQ accuracy notes directly inside each row. |
| **📊 38-Shift Mock Marks Tracker** | Dedicated tracker for all **2025 & 2026 JEE Main Paper 1 shifts** (latest 75-question pattern) with auto-calculated `/300` totals. |
| **💾 Zero-Loss Auto Save & Backup** | Instant persistence using browser `localStorage`, plus one-click **JSON Export / Import** to back up or move data across devices. |
| **📱 Mobile & Tablet Responsive** | Ergonomic dark UI engineered for distraction-free late-night study sessions on phones, tablets, and laptops. |

## 🛠️ Tech Stack & Architecture

- **Frontend:** Semantic HTML5, Modern CSS3 (Grid/Flexbox, Custom Properties, Dark Theme), Vanilla JavaScript (ES6+)
- **Persistence:** Client-side `localStorage` with structured JSON state serialization
- **Performance:** Zero external frameworks, zero build step, instant load times, and 100% offline capability after first visit

## 💻 Run Locally

Want to customize chapters or host your own version? Clone the repository and open `index.html` in any browser:

```bash
# Clone the repository
git clone [https://github.com/RaushanSharmaWeb/JEE-2027-Master-Tracker.git](https://github.com/RaushanSharmaWeb/JEE-2027-Master-Tracker.git)

# Navigate into the project directory
cd JEE-2027-Master-Tracker

# Open index.html in your browser (or use VS Code Live Server)
```
